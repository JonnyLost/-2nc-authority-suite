# 2NC Authority Suite v4.25.0 — Film & Classical Composer Expansion

This release completes a deep retail-coverage audit of film, television, and concert composers while preserving Classical as the established top-level Authority section.

## v4.25.0 changes

- Added 260 previously missing composers: 91 film and screen composers and 169 broader classical composers.
- Assigned 82 Essential and 178 Recommended authority levels after a final retail-usefulness review.
- Added a primary and secondary subgenre to every new composer so vinyl and CD labels retain both requested descriptor lines.
- Preserved all 6,036 existing music records and IDs, locally edited Authority Manager records, retired/deleted records, comics, queues, labels, printing, synchronization, and offline behavior.
- Avoided alias duplication, including Volker Bertelmann/Hauschka and Junkie XL/Tom Holkenborg.
