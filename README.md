# 2NC Authority Suite v4.24.0 — Roots Music Deep Dive

This release completes a deep retail-coverage audit of Country, Blues, Folk, Bluegrass, and Americana while preserving the established Authority taxonomy and all existing authorities.

## v4.24.0 changes

- Added 367 previously missing artists: 79 Country, 83 Blues, 54 Folk, 51 Bluegrass, and 100 Americana.
- Assigned 95 Essential and 272 Recommended authority levels after a final retail-usefulness review.
- Added a primary and secondary subgenre to every new artist so vinyl and CD labels retain both requested descriptor lines.
- Preserved all 5,669 existing music records and IDs, locally edited Authority Manager records, retired/deleted records, comics, queues, labels, printing, synchronization, and offline behavior.
